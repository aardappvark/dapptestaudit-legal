Privacy Policy

Effective: February 2026

DappTestAudit ("the App") is developed by ADappvark ("we", "us", "our"). We are committed to protecting your privacy. This policy explains what data the App handles and how.

Summary: DappTestAudit collects no personal data beyond what is needed for optional GitHub sign-in. All scanning is performed on your device.

1. Data We Do NOT Collect

We do not collect, store, transmit, or process any of the following:

  • Personal information (name, email, phone number, date of birth)
  • Account or login credentials (your GitHub password is never seen by us)
  • Device identifiers or advertising IDs
  • Usage analytics or telemetry
  • Crash reports sent externally
  • Cookies or tracking technologies
  • Repository source code (fetched temporarily for scanning, never stored)

2. Local Storage

The App stores the following data locally on your device only:

  • Wallet connection state — encrypted via Android Keystore (EncryptedSharedPreferences)
  • GitHub OAuth access token — encrypted via Android Keystore (EncryptedSharedPreferences)
  • GitHub username — stored locally for display purposes
  • Disclaimer acceptance — simple boolean flag

This data never leaves your device and is deleted when you uninstall the App or sign out.

3. Network Requests

DappTestAudit makes network requests only for the following purposes:

  • GitHub API — to authenticate via GitHub Device Flow OAuth and to fetch repository file contents for scanning. Only occurs when you choose to sign in with GitHub.
  • Solana RPC — to verify Seeker Genesis Token (SGT) holder status when you connect a wallet. A single read-only request to the Solana mainnet.
  • Mobile Wallet Adapter (MWA) — local device-to-device communication for wallet sign-in via SIWS (Sign In With Solana).

GitHub requests include your OAuth access token for authentication. Repository contents are fetched temporarily into memory for scanning and are never stored, cached, or transmitted elsewhere. No personal data is included in Solana RPC requests.

4. GitHub OAuth

DappTestAudit uses GitHub's Device Flow OAuth, which means:

  • Your GitHub password is never entered into or seen by the App
  • Authentication happens entirely on GitHub's website
  • You can revoke access at any time via GitHub Settings > Applications
  • The App requests "repo" scope to read repository contents for scanning
  • The App does not write to, modify, or delete any repository content

5. File Access

When you select a project directory or APK file for local scanning, DappTestAudit reads those files temporarily in memory. File contents are never stored, cached, or transmitted. Temporary APK copies in the app cache are deleted immediately after scanning.

6. No Accounts

DappTestAudit does not create accounts on any service. GitHub sign-in uses OAuth Device Flow — your credentials are never seen by the App. Wallet connection via Sign In With Solana (SIWS) is optional and does not create an account.

7. Children's Privacy

DappTestAudit is a developer tool not directed at children under 18.

8. Your Rights

Under GDPR, CCPA, Australian Privacy Act 1988, and other applicable privacy laws, you have rights regarding your personal data. Since we collect no personal data, these rights are automatically satisfied. You can delete all locally stored data by uninstalling the App or signing out of GitHub/wallet within the App.

9. Changes to This Policy

We may update this Privacy Policy from time to time. Updated versions will be posted on this page with a new effective date.
