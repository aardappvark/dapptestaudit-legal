What is DappTestAudit?

DappTestAudit is a pre-submission compliance scanner for developers building apps for the Solana Seeker dApp Store. It performs static analysis on your Android project source code and APK files to identify common rejection patterns before you submit.

Features

GitHub Integration

Sign in with GitHub and scan your repositories directly from your Seeker device.

Source Analysis

Scans manifest, build config, wallet patterns, ProGuard rules, and legal assets.

APK Scanning

Analyze built APK files for signing, permissions, and resource compliance.

Rejection Patterns

Checks based on real dApp Store rejection patterns and Play Protect issues.

Important Notice

DappTestAudit is an independent developer tool. It is not affiliated with, endorsed by, or connected to Solana Mobile Inc., Solana Foundation, or the Seeker dApp Store review team. Scan results are advisory only and do not guarantee approval.
